# Learn the flag-memory result

Start with the [Watrous bridge](WATROUS_BRIDGE.md) for the textbook sections and a worked memory setting. The [30 milestones](MILESTONES.md) follow the phase-error model, the arbitrary-processor converse and the attaining receiver.

The educational anchor is John Watrous’s *The Theory of Quantum Information* (2018). The [scientific account](../science/README.md) gives the proof and defines the timing and resource assumptions.
